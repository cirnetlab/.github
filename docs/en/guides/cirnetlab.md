# About CIRNETLAB

[Tiếng Việt](../../vi/guides/cirnetlab.md) · [Documentation](../index.md)

CIRNETLAB is an open electronics laboratory project under development. It
connects browser-based circuit design and simulation with the goal of remote
hardware experiments. Follow the [project website](https://tinihi.cirnetlab.workers.dev/)
and [repositories](https://github.com/orgs/cirnetlab/repositories).

The website demonstrates the project and virtual experiments. Physical lab
readiness requires verification for the selected hardware and release. Use
[CIRNET Remote](https://github.com/cirnetlab/cirnet-remote) for the current
system and its evidence.

The organization profile is served from [profile/README.md](../../../profile/README.md).
Its artwork includes the [CIRNETLAB mascot](../../../asset/mascot.png).
